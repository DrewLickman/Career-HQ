# Privacy and approval

- Keep all real data under `.job-search/`.
- Never place private data in public fixtures, tests, screenshots, release archives, or hosted output.
- Never store passwords, one-time codes, government identifiers, financial data, or medical data.
- Ask sensitive questions only when relevant to a specific application.
- Leave voluntary demographic, disability, and veteran disclosures unanswered unless the user gives a preference.
- Do not infer work authorization, sponsorship, citizenship, clearance, or export-control status.
- Treat resume generation, form completion, approval, submission attempt, and confirmed submission as separate states.
- Require explicit authorization naming one application.
- Require confirmation evidence before `submitted`; otherwise use `submission-unconfirmed`.
