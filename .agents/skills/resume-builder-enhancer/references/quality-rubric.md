# Resume Improvement Quality Rubric

Use this rubric for each audit and final goal gate. Do not use a numeric score; rank only material findings as `high`, `medium`, or `low`.

| Area | Inspect for | Safe action |
| --- | --- | --- |
| Job alignment | Required duties and vocabulary supported by evidence | Reorder and conservatively rephrase verified content; label unsupported requirements `cannot-claim`. |
| Evidence strength | Specific actions, scope, tools, outcomes, and approved metrics | Reuse verified specifics; ask for a missing fact instead of adding one. |
| Summary and bullets | Clear role fit, action-result wording, tense, and duplication | Rewrite only when the source claim still means the same thing. |
| Skills and selection | Relevance, ordering, exclusions, and unsupported skills | Reorder or select verified skills only; never add a posting keyword as a skill. |
| Chronology and accuracy | Conflicting titles, dates, employers, credentials, or numbers | Preserve the conflict and request confirmation; never choose a version. |
| ATS and readability | Plain headings, truthful terminology, scannable structure, and no keyword stuffing | Use natural language from the posting when evidence supports it. |
| Visual presentation | Baseline style, role-title header, page flow, density, spacing, and clipping | Apply safe layout fixes while preserving the source visual system. |

## Final quality gates

Complete the resume-improvement goal only when all of the following are true:

1. The job posting is complete, immutable, current when sourced from a URL, and credible.
2. Every used claim maps to verified evidence with a source and verification date; profile conflicts are resolved or excluded.
3. User exclusions are absent from every generated section and evidence manifest.
4. Every unsupported requirement is visibly classified `cannot-claim` or remains outside the resume.
5. No `high` or `medium` safe fix remains, and every `needs-info` item is either answered or intentionally omitted.
6. The latest DOCX and PDF have been rendered and visually inspected page by page, with the correct role title and no layout defects.
7. A final audit finds no meaningful safe improvement. User review follows goal completion and does not authorize submission.
