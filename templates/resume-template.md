# Neutral resume template

Career HQ generates a compact, single-column resume using the `standard_business_brief` document preset: US Letter, one-inch margins, Arial body text, restrained black/green hierarchy, real Word list structures, and no decorative title border.

Sections are included only when verified evidence exists:

1. Identity and contact line
2. Verified professional summary
3. Relevant verified skills with context
4. Experience grouped by professional, educational, freelance, and personal-project type
5. Evidence manifest stored beside the generated DOCX and PDF

No placeholder claim may survive into generated output.
